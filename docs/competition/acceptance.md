# 工程验收说明

本项目以当前新建项目需求及 README 的公开能力为基线；没有此前已经提交给赛事方的申报书。2026-10-30 24:00 截止日期已过，本记录不证明比赛资格或组委会验收。

## 实现及可复现证据

- 核心：有序项集 I/S 增长、每记录一次支持、无位置约束的精确 Top-K 排行、间距与跨度约束、完整证据枚举、支持索引、群组比较和描述性规则；见 `src` 及公共接口。
- 交换：严格整数 JSON、正整数 SPMF、符号字典；非法输入与预算耗尽抛出类型化错误。
- 生产 MoonBit 1793 物理行；仅根 src 手写生产文件，排除测试、例子、生成接口与参考向量，计入常规注释及空白。运行 `python scripts/audit_source.py` 可复核。
- 178 个测试，包括 864 组独立位置/项子集穷举比较、Top-K 独立 powerset oracle 对照和 128 个 PrefixSpan-py 0.5.2 标量序列差分向量；参考范围不包含上游未实现的多项项集。
- 本地 moonc 0.10.20、moon 0.1.20261104：wasm-gc、wasm、js 的严格 check/build/test 和 wasm-gc 三个例子实际通过；native check 通过，本机缺 MSVC，因此 native build/test/run 本地受环境阻塞。Ubuntu 四后端 CI 必须在公开精确版本 SHA 上全部成功，才能发布。
- README 的三个下游流程：行为路径 4 条记录；服务事件 6 个邻接模式、2 个完整嵌入；符号记录 9 个模式、6 条规则，均有运行断言。Top-K 的排序、并列截断和非法预算另有测试覆盖。

## 审查修复和边界

外部调用原能修改 SupportIndex.snapshot 导致支持数变化，现内部存储私有，输入与结果隔离有回归。item_count 在超过 Int32 的合法共享数组上曾溢出，现使用 Int64；以 2147483648 的精确结果回归。Top-K 明确限制在无位置约束语义，支持度阈值剪枝经过独立 oracle 验证；闭合/极大仅限输入模式族；规则只表达无约束描述统计。
